Project Introduction

IndiaNewsDesk is a full-stack web application that allows users to browse, filter, and bookmark today's Indian newspapers by state and language — covering all 36 states and UTs across 14 Indian languages.

📄 ePaper Access

Each newspaper card links directly to the official ePaper website. Free and login-required papers are clearly marked.

⭐ Bookmarks

Users can save favorite newspapers. Bookmarks are stored permanently in MySQL database via REST API.

Spring Boot — REST API Endpoints

All 9 API endpoints:

GET /api/newspapers All newspapers sorted A–Z
GET /api/newspapers/filter?state=&language= Filter by state + language
GET /api/newspapers/{id} Get one newspaper by ID
GET /api/search?keyword=Hindu Search by name keyword
GET /api/languages All distinct languages
GET /api/states All distinct states
GET /api/stats Count by language + region
GET /api/favorites All saved favorites
POST /api/favorites Save a favorite
DELETE /api/favorites/{id} Remove a favorite

Spring Data JPA + Hibernate ORM

Hibernate automatically converts Java objects ↔ MySQL database rows. No manual SQL needed for basic operations.

List<Newspaper> findByStateIgnoreCaseAndLanguageIgnoreCase( String state, String language); // Custom JPQL query @Query("SELECT n FROM Newspaper n WHERE " + "LOWER(n.name) LIKE " + "LOWER(CONCAT('%',:kw,'%'))") List<Newspaper> searchByName( @Param("kw") String keyword); // Aggregation — group by language @Query("SELECT n.language, COUNT(n) " + "FROM Newspaper n " + "GROUP BY n.language") List<Object[]> countByLanguage(); }

Design Patterns & Best Practices

🏗️ Builder Pattern

Used in Newspaper entity to construct objects fluently:

Newspaper.builder() .name("The Hindu") .language("English") .state("Tamil Nadu") .freeEpaper(true) .build();

🔌 Repository Pattern

All database access goes through Repository interfaces. Controller → Service → Repository. Clean separation.

// Controller calls Service service.getByState(state); // Service calls Repository repo.findByStateIgnoreCase(s); // Repository calls Database

💉 Dependency Injection

Spring auto-creates and injects objects. No new keyword needed. Makes code testable and loosely coupled.

@Service public class NewspaperService { // Spring injects this private final NewspaperRepository repo; }

📦 DTO Pattern (Data Transfer Object)

StatsDTO carries only the data needed by the frontend — total count, favorites count, breakdown by language and region. Avoids exposing raw database objects to the API.

🔒 3-Tier Layered Architecture

Controller → only handles HTTP requests
Service → only contains business logic
Repository → only talks to database
Each layer has one responsibility (Single Responsibility Principle).
